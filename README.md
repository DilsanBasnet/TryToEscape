# TryToEscape - 2D Platformer Game [![Hackatime](https://img.shields.io/badge/Hackatime-32h-ff477e?logo=wakatime&logoColor=white)](https://github.com/DilsanBasnet)

## DEMO: [TRY-TO-ESCAPE](https://dilsanbasnet.itch.io/trytoescape)

* I build this 2d platformer game called TryToEscape. It is a challenging 2d platforming game where patience, timing & precision are keys.
  Players must navigate through parkour level while dodging obstacles likes : spikes, cannnons, rotating blades, moving platforms while collecting collectable items, like coins, gems, coinbox etc.*

  ---

* In this game the player's main goal is to reach the Escape Portal to escape and advance to the next Levels.*
* I build 15 handcrafted levels for now, but I will add more difficult levels later, will new features... The levels test the player timing and reflexes with speed pads, jumping pads & tricky hazards.*
  
  ---

*In this game , there is a continuous background music , which plays in every level continuously, & there are Many sound effects for Jumping, entering Portal, collecting coins, dying.*

## GAME SCENES: 
- **Main Menu Scene** : Play Button, Exit Button, Game Name, Background Sprite etc...
- **Level Scenes** : Game Area , 15 different & difficult Levels, with many game objects; like platforms, player, obstacles, collectingitems, portals, jumpingpad, speedpad, cannons, etc.. many more things/gameobjects.
- **Game Over Scene**: Return to the Main Menu button, Exit Buttons , and GameOver text.

  ## KEY FEATURES:
  - AudioManager : smooth background music , sfx .
  - Custom Game Objects: Jump pads, Speed pads, Moving Platforms, Cannons, Portals.
  - Dynamic Camera Tracking - Player focused CineMachine Camera.
  - etc.....
 
  ## CONTROLS:

  - **A** / **Left Arrow** - Move left
  - **D** / **Right Arrow** - Move Right
  - **SpaceBar** - Jump / Long press for High Jump
  - **Escape Key** - Pause / Resume.
 
  ## BUILD WITH :
  - **Game Engine** - Unity 2D
  - **Programming Language** - C#
  - **Sound Effects & Music** - Opengameart
  - **Sprites** - Pinterest, Pixlr.
